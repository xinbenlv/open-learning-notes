# Open Learning Notes · 开放学习讲义

Interactive, bilingual lecture notes on important computer-science and software-engineering ideas — built so you can *operate* the figures and discover the relationships yourself, not just read about them. Explained like Feynman, questioned like Socrates.

用交互式图解讲清楚重要的计算机与软件工程概念:图不是用来看的,是用来拨弄的。像费曼一样讲清楚,像苏格拉底一样问到底。

## How to participate · 如何参与

- **Feynman PR** — you can explain a concept more simply, or make a figure teach a relationship better? Open a pull request. The first line of your PR should say *which concept you made simpler*.
- **Socratic Issue** — you don't believe it, don't follow it, or think it's wrong? Open an issue with the `socratic` label. Every yearly edition's changelog credits the questions that changed the text.

- **费曼式 PR**:你能把某个概念讲得更简单、或让某张图更能解释关系?提 PR,第一行写明你把哪个概念讲简单了。
- **苏格拉底式 Issue**:不信、不懂、觉得讲错了?开 issue,打 `socratic` 标签。每年新版的更新日志都会致谢那些改变了正文的提问。
